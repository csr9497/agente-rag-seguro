# Base de conocimiento de TI: el portátil no enciende

Si el portátil corporativo no enciende:

1. Conecta el cargador original y espera 15 minutos antes de intentarlo de nuevo.
2. Mantén pulsado el botón de encendido durante 20 segundos para forzar el reinicio.
3. Comprueba si el indicador de carga se enciende; si no lo hace, prueba otro enchufe.

Si sigue sin encender, abre un ticket a Soporte IT. Un equipo que no enciende y del que
dependes para trabajar se considera prioridad alta; si afecta a un servicio crítico para
varios equipos, Soporte IT puede clasificarlo como P1.
