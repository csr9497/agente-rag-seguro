# Base de conocimiento de TI: la VPN no conecta

Si la VPN corporativa no conecta desde casa:

1. Comprueba que tienes conexión a Internet abriendo cualquier página web.
2. Cierra el cliente de VPN por completo y vuelve a abrirlo.
3. Verifica que usas tu usuario corporativo y el código de verificación en dos pasos.
4. Si el error indica «certificado caducado», reinicia el equipo para que se renueve.

Si después de estos pasos sigue sin conectar, abre un ticket a Soporte IT indicando el mensaje
de error exacto y desde qué red intentas conectar.
